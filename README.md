# GravityGauge

A simple web application that calculates your weight on different planets in our solar system based on your weight on Earth. Built using HTML, CSS, and JavaScript.

## Features

- Enter your weight on Earth in kilograms
- Instantly calculate your weight on all planets: Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune
- Responsive design with planet images
- Easy-to-use interface

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Enter your weight on Earth in the input field
4. Click the "Calculate Weights" button
5. View your calculated weights on each planet

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
